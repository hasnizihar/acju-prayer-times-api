# SalahSL API

The **SalahSL API** provides independent prayer-time infrastructure for Sri Lanka, built by KR Hasni Zihar.

Prayer-time data is sourced from the **All Ceylon Jamiyyathul Ulama (ACJU)**. This is an independent implementation and is not an official ACJU API.

## Core Principle

This API is designed as infrastructure. It provides structured JSON responses for geographical resolution, location metadata, and precise prayer times across 13 regions in Sri Lanka. It is built to be consumed by any modern client application, widget, or backend service.

## Features

- **GPS Resolution**: Resolve any coordinate within Sri Lanka to its correct ACJU region.
- **RESTful Endpoints**: Consistent JSON formatting for all requests.
- **Location Support**: First-class support for all 13 ACJU-defined regions.
- **OpenAPI Compliant**: Fully documented API contract.
