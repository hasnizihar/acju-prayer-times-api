# Today's Prayer Times

`GET /api/v1/prayer-times/today`

Returns the prayer times for the current day based on the `Asia/Colombo` timezone.

## Parameters

| Parameter | Type   | Required    | Description |
| --------- | ------ | ----------- | ----------- |
| `lat`     | number | conditional | Latitude of the location in Sri Lanka. |
| `lng`     | number | conditional | Longitude of the location in Sri Lanka. |
| `location`| string | conditional | The slug of the location (e.g. `batticaloa-ampara`). Required if `lat`/`lng` are not provided. |

## Errors

- `400 Bad Request`: Missing location/coordinates, invalid format, or coordinates outside Sri Lanka.
- `404 Not Found`: Location not found or data not available.
- `429 Too Many Requests`: Rate limit exceeded.
- `500 Internal Server Error`: Internal server error.

## Cache

`Cache-Control: max-age=300` (5 minutes)

## Source

All prayer times are sourced from the **All Ceylon Jamiyyathul Ulama (ACJU)** dataset.
