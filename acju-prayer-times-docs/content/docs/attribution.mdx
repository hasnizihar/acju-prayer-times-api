# Data & Attribution

The API infrastructure and the prayer-time data it serves are separate entities. 

### API Software

The API software and infrastructure are independently developed by **KR Hasni Zihar**.

### Prayer-Time Data

Prayer-time data is sourced from the **All Ceylon Jamiyyathul Ulama (ACJU)**. 

> **Important**: This is an independent API using prayer-time data sourced from ACJU. It is not an "Official ACJU API", and its use does not imply endorsement by the ACJU.

You can verify the original source data at:
[ACJU Prayer Times](https://www.acju.lk/prayer-times/?utm_source=chatgpt.com)

### Geographic Data

The geographic resolution engine uses boundary data and administrative mapping for Sri Lanka. The geographic datasets used for coordinate resolution are subject to their respective open-source licenses as documented in the API repository.
