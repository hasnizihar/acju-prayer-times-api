# Getting Started

The ACJU Prayer Times API is a public JSON REST API. It is completely independent and requires no authentication or API keys.

### Step 1: Base URL

The current production API base URL is:

```text
https://acju-prayer-times-api.vercel.app/api/v1
```

### Step 2: Choose a Location

You can fetch prayer times by coordinate, but it is faster and more reliable to request times using an official ACJU location slug.

To see all 13 locations:

```http
GET /api/v1/locations
```

### Step 3: Request Prayer Times

Request today's prayer times for a given coordinate:

```http
GET /api/v1/prayer-times/today?lat=7.2906&lng=81.6337
```

### Step 4: Consume Response

The response format is consistent across all data endpoints.

```json
{
  "data": {
    "location": {
      "slug": "batticaloa-ampara"
    },
    "date": "2026-08-25",
    "prayer_times": {
      "fajr": "04:37",
      "sunrise": "05:56",
      "dhuhr": "12:07",
      "asr": "15:15",
      "maghrib": "18:16",
      "isha": "19:26"
    }
  }
}
```

## Quick Start Examples

**cURL**
```bash
curl "https://acju-prayer-times-api.vercel.app/api/v1/prayer-times/today?lat=7.2906&lng=81.6337"
```

**JavaScript**
```javascript
const response = await fetch(
  "https://acju-prayer-times-api.vercel.app/api/v1/prayer-times/today?lat=7.2906&lng=81.6337"
);

const result = await response.json();
console.log(result.data.prayer_times);
```

**Python**
```python
import requests

url = "https://acju-prayer-times-api.vercel.app/api/v1/prayer-times/today"
params = {"lat": 7.2906, "lng": 81.6337}

response = requests.get(url, params=params)
print(response.json()["data"]["prayer_times"])
```
